1. 给 Agent 一个"工位"：多 Agent 工作台集中爆发 ​

同一个星期，五个"Agent 工作台"同时上榜。单个 Agent 不够用之后，组织者出现了。

Craft Agents
上榜 2 天开源 Apache 2.0文档式 UI

笔记软件 Craft.do 团队出品的开源 Agent 工作空间，自带模型 key 即可用。

关键观察

最大的不同是不做 CLI、做文档式 UI：多个 Agent 会话像收件箱一样排列，任务有状态流。

产品细节

做笔记软件 Craft.do 的欧洲团队出品（据报道今年 6 月已被 Polymarket 收购）。用自然语言就能连接 Linear、Slack、Gmail 等任意 API/MCP 服务，自动配好凭据；多个 Agent 会话像收件箱一样排列，任务有 Todo → In Progress → Needs Review 的状态流。开源（Apache 2.0），团队宣称整个产品就是用 Craft Agents 自己迭代出来的。

Harness by Autonomous
上榜 2 天全栈开源 MIT配套 $149 触屏硬件

智能升降桌厂商 Autonomous 出品的 Agent 指挥中心：所有编程 Agent、所有机器，统一管理。

关键观察

最有跨界反差感的一个——软硬件一体，还把 Agent 能力扩展到 49 个“代码之外”的领域。

产品细节

统一管理 14+ 编程 agent（Claude Code、Codex、Devin 等），跨机器只要密码配对（WebRTC 直连、端到端加密），不用折腾 SSH key。软件全栈开源（MIT），还做了个 $149 的圆形触屏硬件放桌上盯 Agent 状态。它的 DSH 商店把 Agent 能力扩展到 Blender、电路、机器人等 49 个"代码之外"的领域。

Parallax
上榜 2 天$11.99/月发布当日 99 赞 · 日榜第 11

务实派多 Agent 并行工作台，本地优先，复用你自己的 CLI 订阅。

关键观察

明确不做 Agent 间自动编排，只专注“组织与切换”——取舍比功能堆砌更值得关注。

产品细节

多 Agent 并排跑（可命名 builder/reviewer 角色）、内置编辑器与本地 Git、面板布局按项目记忆。PH 页面显示发布当日 99 upvotes、日榜第 11。注意：只有 Windows 和 Linux 版，没有 macOS。

Dropstone CLI
上榜 1 天免费档可用Pro $15/月

终端里的“学习型”编程 Agent：纠正一次，跨会话记住。

关键观察

CLI/Chat/SDK/编辑器共享同一记忆，基于每月重评的开源模型运行以压低成本。

产品细节

纠正一次，跨会话记住，CLI/Chat/SDK/编辑器共享同一记忆；交付前自己跑命令和测试验证。基于每月重评的开源模型运行以压低成本。

guilds.run
上榜 1 天开源自托管免费发布当日日榜第 4-5 名

关键词是“可审计”的多智能体平台，模型任意混搭，开源自托管免费。

关键观察

每个 agent 的完整 prompt、每次工具调用、每条记忆变更全部留痕，出错能定位到具体哪一步。

产品细节

模型任意混搭（Claude/GPT/Grok/开源模型），Recipes 可以把整支 agent 团队打包成一个文件分享。第三方榜单显示发布当日冲到日榜第 4-5 名、约 158-183 upvotes，是上周表现最好的新产品之一。

工作台解决的是"管一群 Agent"的问题；Agent 真要进生产环境，信任、成本与安全这三道坎随之而来。

2. Agent 进生产：信任、成本与安全"治理三件套" ​

Agent 真要干活了，三个以前不存在的市场出现了。

withHuman
上榜 2 天开源自托管免费YC 23 · Palantir 背景

AI Agent 的人工审批层：常规操作自动放行，高风险操作路由给对应负责人。

关键观察

最妙的决策是把审批协议做成了开放标准 AAP——集成面向协议而非厂商，不怕锁定。

产品细节

拦截 Agent 的工具调用，退款、转账这类高风险操作路由给对应负责人——审批触达 Slack、短信甚至 WhatsApp。审批协议 AAP 以 Apache-2.0 开源。创始人是 YC 23 届、Metoro 团队，CEO 曾任 Palantir 工程师。

Navige
上榜 2 天按节省效果付费发布当日 232 赞（第三方）

Agent 成本管控中间层，定位“事前干预”而不是事后看账单。

关键观察

定价模式本身值得学习——按实际节省效果付费。

产品细节

把合适的请求路由给小模型、缓存重复调用、拦截失控循环。月节省超过 $45 才收节省额的 20%，否则只收 $9，还有个永久免费的 Watchtower 观测模式。第三方日报显示发布当日获 232 赞。

Epherem
上榜 2 天55 项检查早期免费 · 每天 5 次

专为“AI 生成的应用”做的安全扫描器，目标用户是 vibe coder。

关键观察

每个发现都附带可直接粘贴给 Cursor/Claude Code 的修复 prompt，形成“扫描→AI 修复→复扫”闭环。

产品细节

用 Lovable、Cursor 写完应用但自己不读代码的人，上传 ZIP 或连 GitHub，55 项检查覆盖暴露的 API key、开放数据库表、缺失权限校验。报告诚实分级，明确列出扫不到的部分。

治理三件套管的是 Agent 的行为；下一批产品做的是另一件事——把传统软件改造成 Agent 能直接读写的样子。

3. 万物皆可 Agent-Native ​

传统软件正在被挨个改造成"Agent 可读写的接口"。

Cube Forms
上榜 1 天目前免费发布当日日榜第 17

人和 AI Agent 都能填的表单，可通过 MCP 直接创建和填写。

关键观察

同一个链接，人看到正常网页表单，Agent 读到纯文本结构——双模态是 Agent-Native 的最小样本。

产品细节

典型场景：让 Claude Code 自动填好 bug 报告（堆栈、版本、复现步骤），人检查后一键提交。独立开发者作品，据其 LinkedIn 发布当日进入日榜第 17。

EditUI
上榜 2 天MIT 开源Chrome/Firefox 扩展

前端走查神器：点击元素写一句修改意见，攒成批次一键粘贴给任何 coding agent。

关键观察

解决的是“跟 AI 描述哪个按钮”这个天天遇到的沟通成本。

产品细节

在运行中的页面上点击任意元素、写一句修改意见，它自动捕获 DOM 结构、class、计算样式等上下文。零配置、本地优先（Chrome/Firefox 扩展）。

ExcaliClaw
上榜 1 天€9/月起发布当日约 80 赞（第三方）

Excalidraw 手绘白板 + MCP：Claude、Cursor、VS Code 可以直接在你的白板上画图、改图。

关键观察

Agent 终于不用拿 ASCII art 画架构图了。

产品细节

持久化保存、版本历史、实时协作齐全。独立开发者作品，第三方日报显示发布当日约 80 upvotes。

SuperLocalMemory V2
上榜 2 天AGPL-3.0 免费npm 下载 56k+

本地优先的 AI 记忆系统：通过 MCP 接入 17+ 开发工具，一处记忆处处可用。

关键观察

最与众不同的是“治理型记忆”——检索不到时明确回答“没有该记忆”而不是编造。

产品细节

接入 Claude Code、Cursor 等 17+ 开发工具，带信任评分、可回滚、GDPR 导出。开源（AGPL-3.0）免费，官网称 npm 下载 56k+。

Exodus for Google Cloud Run
上榜 2 天开源免费本地审计不上传源码

“零自有 AI”的迁移工具：不内置任何模型，给你已有的 coding agent 提供 Cloud Run 迁移的结构化知识。

关键观察

官方案例展示一个应用从 Railway $48/月降到 Cloud Run $10.83/月。

产品细节

本地审计代码库（不上传源码）、生成账单对比报告、把 Redis 队列/定时器等改造成 Cloud Run 原生方案。官方案例：Railway $48/月 → Cloud Run $10.83/月。

4. AI 落地：从机器人云到监控摄像头 ​

Dreamscale Labs
上榜 2 天YC F26按需计费 · 需申请接入

YC F26 的机器人实时云端推理平台。

关键观察

押注一个反共识方向：机器人模型越来越大，与其给每台机器人装昂贵 GPU，不如推理上云。

产品细节

机器人模型（VLA/WAM）越来越大，单张 H100 并发跑 8+ 台机器人，DreamZero 14B 推理 320ms，比 NVIDIA 官方实现快 8% 且只用一半 GPU。

Grablo Spot
上榜 2 天免费全功能树莓派即可运行

韩国团队做的免费 AI 监控检索，接入你已有的摄像头。

关键观察

录像和 AI 分析全在本地设备上，免费版即全功能、不限摄像头数量，树莓派就能跑。

产品细节

接入已有摄像头（RTSP/ONVIF），按人脸、外观描述（"穿黄衬衫的人"）、模糊车牌秒级定位目标，还能跨摄像头追踪轨迹。

Actually Asked
上榜 2 天免费版 50 次/月付费 $12/月起

会自我进化的网站 FAQ：答案严格只取自你自己的页面和文件，绝不编造。

关键观察

被反复问到的问题自动沉淀进 FAQ，每周邮件告诉你“哪些问题网站答不上来”。

产品细节

被反复问到的问题 30 天内自动沉淀进 FAQ。不是聊天气泡，是继承站点样式的原生区块。免费版 50 次回答/月，付费 $12/月起。

Backdrop
上榜 2 天1000+ 集成YC W23

YC W23 团队转型的“AI 同事”平台：按岗位创建 AI coworker，配好工具、上下文和指令。

关键观察

人、AI、客户同处一个对话协作，跨人员与项目共享记忆。

产品细节

1000+ 集成（Slack、Linear、QuickBooks 等）。创始人是 ex-Microsoft/Uber 的 Forbes 30 Under 30 入选者。

5. 上周的"大家伙" ​

Step 3.5 Flash本期热度王
上榜 2 天SWE-bench Verified 74.4%Apache 2.0 全量开源

阶跃星辰开源的 Agent 基座模型：196B 稀疏 MoE，256K 上下文。

关键观察

难得的是连训练框架一起全量开源，且已适配国产芯片；PH 发布当日拿下日榜第一。

产品细节

196B 稀疏 MoE 每 token 只激活 11B，256K 上下文，SWE-bench Verified 74.4%。难得的是连训练框架（Steptron）一起全量开源（Apache 2.0），且已适配华为昇腾等国产芯片。PH 页面显示今年 3 月发布当日拿下日榜第一。

Apple HomePod mini 2
上榜 2 天$149 买断芯片 S5 → S10

时隔六年的更新，苹果生态用户的家庭中枢。

关键观察

它也提醒我们：PH 榜单从来不只属于软件。

产品细节

芯片从 S5 跳到 S10，支持 Wi-Fi 6E 和更强端上 AI，顶部新增随音乐律动的发光触控屏。$149 买断（比初代贵 $50）。

RazorPay
上榜 2 天YC W15评分 4.33/5 · 184 条评价

印度金融科技独角兽（YC W15），一个平台覆盖收款、付款、发薪、信贷，区别于 Stripe 式纯网关。

关键观察

上线了面向 Agent 场景的 Agentic Stack——支付基础设施也在为 Agent 经济做准备。

产品细节

值得注意的是它上线了面向 Agent 场景的 Agentic Stack。PH 页面显示评分 4.33/5、184 条评价。

7. 写在最后 ​

✅本期结论
  • GitHub 侧在造引擎（编排框架、记忆系统、检索基建），PH 侧在卖整车（工作台、审批层、按效果付费的降本服务）——两份榜单放在一起，是同一场变革的两面。
  • 2026 年下半年，Agent 竞争的焦点已经不是“谁的模型强”，而是谁先把 Agent 的管理、信任与成本问题产品化。
  • 上周 PH 上跑得最好的新产品（guilds.run 日榜前五、Navige 232 赞），卖点都不是“更聪明的 AI”，而是“更可控的 AI”——信任，正在成为 Agent 产品的第一卖点。
