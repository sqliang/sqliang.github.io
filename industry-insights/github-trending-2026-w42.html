上周 19 个上榜项目中，超过一半与 Agent 生态直接相关。更有意思的是，它们不是零散的工具，而是拼出了一幅完整的图景：有给 Agent 装"应用商店"的（插件与技能市场），有让 Agent 成群结队干活的（多智能体编排），有解决 Agent"记性差、太烧钱"的（记忆与检索），还有给 Agent 做"审计"的。

与此同时，rust、nvm、ghidra 这些底层常青树也在同周上榜——AI 浪潮越猛，地基越值钱。

1. 上周最大信号：Agent 插件与技能市场集中爆发 ​

同一个星期，四个"Agent 应用商店"同时上榜，这在以往并不多见。平台方（Anthropic、Cursor、Google）和第三方社区都在抢这个生态位。

anthropics/claude-plugins-official ↗
上榜 3 天约 43.1k Star官方插件市场

Anthropic 官方 Claude Code 插件市场，统一管理官方与社区插件。

关键观察

“插件名不可变”的迁移设计，解决插件改名导致老用户安装失效的问题。

项目细节

仓库本身即市场清单，分官方插件和社区插件两个区，社区插件需通过质量与安全审核才能上架。即使插件改名，老用户的安装也会通过 renames 映射自动迁移，不会出现"一觉醒来插件找不到"的情况。安装只需一行：/plugin install {name}@claude-plugins-official。

cursor/plugins ↗
上榜 1 天约 100 个插件官方插件仓库

Cursor 官方插件仓库，覆盖开发者工具、生产力与 SaaS 集成。

关键观察

orchestrate、thermos、advisor 等插件，把并行编排、分支审查和专家咨询做成标准工作流。

项目细节

约 100 个插件覆盖三大类：开发者工具、生产力、SaaS 集成（GitHub、Salesforce、Google 全家桶，甚至 Robinhood/Coinbase 交易）。其中，orchestrate 可以编排并行云端 Agent，thermos 做深度分支审查，advisor 则在关键决策时咨询更强的模型。

android/skills ↗
上榜 2 天官方 Skills兼容主流 Agent

Google Android 官方 Agent Skills，补齐 Agent 在特定开发场景中的短板。

关键观察

只补评测中表现不佳的场景，确保生成代码符合官方最佳实践。

项目细节

它不教 LLM 已经会的基础 Compose 用法，只补评测中表现不佳的短板场景（如 R8 分析、Wear Compose M3），确保 Agent 生成的代码符合 developer.android.com 的官方最佳实践。兼容 Claude Code、Codex、Gemini 等主流 Agent。

K-Dense-AI/scientific-agent-skills ↗本期热度王
上榜 4 天52.8k Star覆盖科研场景

177 个科研技能与 100+ 科学数据库接入，把任意 AI Agent 变成科研助手。

关键观察

每个技能都带文档、示例、测试与安全扫描报告，是 Skills 生态少见的认真样本。

项目细节

上周唯一连续 4 天上榜的项目。技能覆盖生物、化学、医学、药物研发等场景，数据库接入包括 PubChem、ChEMBL、UniProt 等。每个技能都带 SKILL.md 文档、代码示例和测试套件，还公开了 Cisco AI Defense 的安全扫描报告。

插件与技能只是入口；接下来还会看到多 Agent 编排、记忆与成本、以及信任审计等配套基础设施。

2. 从"一个 Agent"到"一支 Agent 舰队" ​

单个 Agent 的能力见顶后，上周的三个项目给出了同一个答案：管一群。

stablyai/orca ↗
上榜 1 天约 97.8k StarYC 背书

多 Agent 编排 IDE，把一个 prompt 分发给多个在独立 worktree 中运行的 Agent。

关键观察

支持 30+ 种 CLI Agent 与移动端远程指挥，把“择优合并”做成日常开发工作流。

项目细节

上周 Star 数最高的新项目，定位是"100x 开发者的 AI Agent 编排 IDE"。它还配了 iOS/Android 伴侣 App，可以在手机上远程监控和指挥 Agent 干活；内置 VS Code 编辑器、GitHub/Linear 集成、WebGL 终端。"能在终端跑，就能在 Orca 跑"，并且每日发版。

ruvnet/ruflo ↗
上榜 3 天多智能体编排跨机器协作

多智能体编排 Harness，提供 100+ 专业化 Agent、拓扑与跨机器协作。

关键观察

官方把性能作为核心卖点，也再次证明 Agent 竞争力不只在模型，而在 Harness。

项目细节

前身是大名鼎鼎的 Claude Flow，支持层级、mesh、自适应 swarm 拓扑、亚毫秒级向量记忆（AgentDB + HNSW）和跨机器零信任 Federation。官方 benchmark 宣称对比 LangGraph/AutoGen/CrewAI 快 1.3 到 1953 倍——数字夸张，但至少说明它把性能当成了核心卖点。值得记住的是：Agent = Model + Harness，模型之外的那层"外壳"才是真正的竞争力。

HKUDS/CLI-Anything ↗
上榜 3 天覆盖 18 款软件2280+ 项测试

自动把专业软件改造成 Agent 可调用的 CLI 与 API。

关键观察

直连真实软件后端并附带测试，比截图驱动的 GUI Agent 更快、更稳定。

项目细节

香港大学数据智能实验室出品，思路非常激进：让全世界所有软件都变成 Agent-Native。运行 /cli-anything ./gimp，它会自动分析软件源码、把 GUI 操作映射为 API，生成带测试和文档的完整 CLI——直连真实软件后端（Blender 真的渲染 3D，LibreOffice 真的生成 PDF），不是玩具。配套 CLI-Hub 包管理器分发社区成果。

3. Agent 的"记性"和"钱包" ​

Agent 落地到日常开发，两个最实际的痛点：记不住事、太烧 token。上周两个项目分别对症。

akitaonrails/ai-memory ↗
上榜 1 天支持 20+ Agent零 LLM 调用

跨工具、跨机器的长期记忆系统，让 20+ 种 Agent 共享同一个记忆库。

关键观察

以 Git 版本化 Markdown 存储且默认零 LLM 调用，兼顾可迁移性、可读性和成本。

项目细节

痛点很真实：你在 Claude Code 里干到一半，想换 Codex 继续，就得重新解释一遍架构、失败过的方案、遗留问题。ai-memory 支持显式的任务交接协议，兼容 Claude Code、Codex、Cursor、Gemini CLI、Kimi 等工具；记忆可以直接用 Obsidian 打开。作者是巴西 Ruby 社区名将 Fabio Akita。

xerj-org/xerj ↗
上榜 3 天本地优先MCP 检索

Rust 编写的本地搜索引擎，让 Agent 通过 MCP 检索精确片段而不是读取整个文件。

关键观察

实测比 grep 驱动的 Agent 少花 2.7 倍输出 token，解决率持平。

项目细节

一条 xerj autoindex 命令可索引代码、PDF、日志和邮件；代码经 tree-sitter 做 AST 感知解析。它还完整兼容 Elasticsearch API，基准测试对 ES 8.13.4 打出 55 胜 26 平 4 负。

Alishahryar1/free-claude-code ↗
上榜 1 天61 家供应商11 种 Agent

本地代理聚合 61 家模型供应商，为 11 种编程 Agent 提供统一接入与故障切换。

关键观察

这类项目上榜，说明官方订阅价格已经成为开发者真实痛点。

项目细节

它宣称每月聚合 13 亿+ 免费 token，统一接入 Claude Code、Codex、Aider 等工具，供应商挂了自动切备用。作者强调"ToS-friendly"，不碰灰色接口。

4. Agent 可信吗？ ​

Agent 进生产环境后，"它到底有没有在干该干的事"成了刚需问题。

ifixai-ai/iFixAi ↗
上榜 1 天60 项检查A–F 评级

AI Agent 独立审计工具，按业务对齐度而不是只看技术指标评分。

关键观察

60 项检查被归为五大风险支柱，并由不同厂商的独立模型交叉打分。

项目细节

五大支柱包括伪造、操纵、欺骗、不可预测和不透明。它采用 SUT + Judge 双角色设计，号称 120 秒内出结果。案例库很扎心：用 Pizza Hut 投诉机器人、Instagram 接管事件等真实事故重建的测试 fixture，全被评为 F。

vxcontrol/pentagi ↗
上榜 1 天约 31.3k Star本地部署

全自主 AI 渗透测试系统，由专职智能体完成侦察、攻击规划、执行与报告。

关键观察

20+ 安全工具在沙箱中隔离运行，并明确说明当前不是完整的 BAS 产品。

项目细节

你用自然语言描述目标，Orchestrator 会协调 Researcher、Developer、Executor 等专职智能体完成任务。内置 nmap、Metasploit、sqlmap 等工具，数据完全跑在自有基础设施上，支持 Ollama/vLLM 本地模型，适合隔离网络。

5. 上周同样值得关注的"非 Agent"项目 ​

bilawalsidhu/gods-eye-view ↗
上榜 3 天约 58k Star日榜/周榜双第一

浏览器里的 3D 实时地球，聚合航班、船舶、卫星、地震与公共摄像头数据。

关键观察

20+ 个真实公开数据图层被做成可交互界面，还能作为 MCP Server 供 Claude 调用。

项目细节

它聚合 1.1 万架航班、船舶 AIS、838 颗卫星、地震、火情、约 4000 个公共摄像头和气象风场，支持 OpenAI Realtime 语音控制、座舱视角跟拍飞机和军事风 HUD 滤镜，并获 JavaScript 之父 Brendan Eich 点赞。

LibreSpark/LibreTV ↗
上榜 1 天约 2 万 Star约 2.9 万 Fork

免费开源的影视聚合搜索与观看平台，Docker 一条命令即可自建。

关键观察

Fork 远超 Star，说明二次开发和私有部署比点赞更活跃。

项目细节

Next.js 15 重写后体验不错，提供聚合搜索、HLS 播放去广告、IPTV 直播和进度本地续播。它是榜单上的老面孔，也代表了一类适合个人自托管的开源产品。

microsoft/BitNet ↗
上榜 1 天41.2k StarCPU 推理

微软官方 1-bit 大模型推理框架，让 100B 模型在普通 CPU 上运行。

关键观察

x86 最高 6.17 倍提速、能耗降低 82%，持续压低大模型本地部署门槛。

项目细节

它用查表内核替代通用矩阵乘法，让 1.58-bit 三值模型在普通 CPU 上运行；单 CPU 可跑 100B 模型（5–7 tokens/s）。这类工作正在持续压低大模型本地部署的成本门槛。

NationalSecurityAgency/ghidra ↗
上榜 2 天91.4k Star逆向工程

NSA 出品的开源逆向工程框架，是 IDA Pro 的主流免费替代。

关键观察

反汇编、反编译与图形化分析能力齐全，是安全研究员的装机必备。

项目细节

Ghidra 提供反汇编、反编译、图形化分析以及 Java/Python 脚本扩展，覆盖安全研究员日常逆向分析的核心需求。

rust-lang/rust ↗
上榜 1 天系统语言基础设施

无需 GC 也能保证内存安全的系统语言本体。

关键观察

上层 AI 应用越热闹，底层语言的性能与安全性越保值。

项目细节

Rust 出现在 Trending 上通常不意味着新闻，但它提醒我们：当上层应用快速变化时，能长期支撑这些应用的底层工具反而更加刚需。

nvm-sh/nvm ↗
上榜 1 天Node.js基础设施

Node.js 版本管理的事实标准。

关键观察

版本管理这类“看不见的底层设施”，依然支撑着日常开发环境。

项目细节

nvm 与 Rust 一样，出现在榜单上未必代表新变化，但说明开发环境、版本管理和运行时基础仍然是工程师每天都要依赖的底层设施。

7. 结语 ​

✅本期结论
  • 2026 年下半年的主题是 Agent 生态的标准化与规模化：插件市场解决分发，编排系统解决协作，记忆与检索解决成本，审计工具解决信任。
  • 对开发者来说，入场券是先摸熟一个常用 Agent（Claude Code / Cursor / Codex）的官方插件市场与 Skills 机制。
  • 下一期可继续观察：插件审核标准、多 Agent 协作体验、记忆与检索成本，以及审计工具是否会持续进入 Trending。
